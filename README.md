C Programming Practice

A collection of small C programs I have written while learning programming fundamentals and problem-solving.

## Topics covered

- Basic syntax, variables, and data types
- Input and output
- Operators and conditional statements
- Loops
- Number-based problem solving
- One-dimensional arrays

## Programs

### Basics and number problems

- `hello_world.c` — prints a simple message to the screen. This is a first example of a C program and its output.
- `calculator.c` — performs basic arithmetic using values entered by the user. It practices input, operators, and displaying results.
- `even_odd.c` — checks whether an integer is divisible by two. It practices the remainder operator and conditional statements.
- `positive_negative_zero.c` — determines whether a number is positive, negative, or zero using comparisons and conditionals.
- `largest_three_numbers.c` — compares three numbers and identifies the greatest value. It practices combining conditions.
- `leap_year.c` — checks whether a year meets the rules for being a leap year. It practices arithmetic conditions and logical operators.
- `factorial.c` — calculates the factorial of an input number. It practices repetition and updating a running product.
- `prime_number.c` — checks whether an input number is prime by testing its divisors. It practices loops and conditional logic.
- `reverse_number.c` — reverses the digits of an integer. It practices extracting digits with division and the remainder operator.
- `sum_n_natural_numbers.c` — calculates the sum from 1 through an entered value of n. It practices loops and accumulating a total.
- `sum_of_digits.c` — adds the digits of an integer. It practices processing a number one digit at a time.
- `sum_of_odd_numbers.c` — calculates the sum of odd numbers in the program's chosen range. It practices checking odd values and accumulating a total.
- `multiplication_table.c` — displays multiples of an entered number. It practices loops and formatted output.
- `number_guessing_game.c` — lets the user guess a number and gives feedback. It practices input, comparisons, and repeating a turn until the game ends.

### Arrays

- `array_input_output.c` — reads values into an array and displays them. It introduces indexed storage and looping through elements.
- `array_sum.c` — adds the values stored in an array. It practices traversing an array and maintaining a running total.
- `array_average.c` — calculates the mean of the array values. It combines array traversal, summation, and division.
- `array_largest.c` — searches an array for its greatest value. It practices comparing each element with the current maximum.
- `array_smallest.c` — searches an array for its smallest value. It practices comparing each element with the current minimum.
- `array_even_odd.c` — examines array values to identify even and odd elements. It practices combining array traversal with the remainder operator.
- `array_reverse.c` — displays or rearranges array elements in reverse order. It practices working with array indices from opposite ends.
- `array_sort.c` — puts array elements in order. It practices comparing and rearranging values.
- `array_largest_function.c` — finds the largest value in an array using a separate function. It practices passing an array and its size to a function and returning a result.

## Compile and run

Compile a program with GCC (replace the filename with the program you want to run):

```bash
gcc hello_world.c -o hello_world
```

Run it on Windows:

```bash
hello_world.exe
```

On macOS or Linux:

```bash
./hello_world
```
